STEP 1: Create GitHub Repository
─────────────────────────────────
1. Go to: https://github.com/new
2. Repository name: chatapp
3. Choose Private or Public
4. ❌ DO NOT check "Add README" or any other boxes
5. Click "Create repository"
6. Copy your repository URL (looks like):
   https://github.com/YOUR_USERNAME/chatapp.git


STEP 2: Run These Commands in Your Terminal
────────────────────────────────────────────

📍 Make sure you're in the project folder: e:\Protfolio

Then run these commands ONE BY ONE:

┌─────────────────────────────────────────────────────────────┐
│ Command 1: Add GitHub Remote                                │
│ (Replace YOUR_USERNAME with your actual GitHub username)    │
└─────────────────────────────────────────────────────────────┘

git remote add origin https://github.com/YOUR_USERNAME/chatapp.git


┌─────────────────────────────────────────────────────────────┐
│ Command 2: Rename Branch to Main                            │
└─────────────────────────────────────────────────────────────┘

git branch -M main


┌─────────────────────────────────────────────────────────────┐
│ Command 3: Push to GitHub                                   │
└─────────────────────────────────────────────────────────────┘

git push -u origin main


STEP 3: Enter Credentials When Prompted
────────────────────────────────────────
Username: your_github_username
Password: your_personal_access_token (NOT your GitHub password!)

Don't have a token? Get one here: https://github.com/settings/tokens


═══════════════════════════════════════════════════════════════

✅ DONE! Your code is now on GitHub!

Visit: https://github.com/YOUR_USERNAME/chatapp
